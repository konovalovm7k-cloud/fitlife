## Активация ещё не завершена

`GEMINI_API_KEY` пока отсутствует (`wrangler secret list`: `[]`).
Перенос ключа из AI Studio в Cloudflare ожидает отдельного разрешения владельца.
Не помещайте его в исходники, APK, чат, обычную переменную или командную строку.
Сохранять его следует только как Worker Secret.

Настоящий запрос к Gemini ещё не выполнен. `/health` проверяет только доступность
Worker: он не проверяет наличие ключа, доступность модели, квоту или качество AI.
До добавления секрета анализ вернёт HTTP 503 `configuration`.

После сохранения секрета нужно проверить фото блюда и фото без еды через настоящий
сервер, затем подключение Samsung S23. Без этого функция не считается принятой.

## Подключение телефона

Установите подписанный `dist/FitLife-4.4.0-release.apk`. Откройте «Камера» ->
«Подключить сервер распознавания», введите адрес выше и личный код из
`server/private/owner.txt` на компьютере владельца. Этот файл исключён из Git;
не публикуйте его. Не добавляйте к адресу `/v1/analyze`.

На физическом телефоне настройка и распознавание ещё не проверены.
APK не изменялся при развёртывании: адрес настраивается в приложении.

## Обслуживание

Инструкция для нового сервера, выдачи и отзыва индивидуальных кодов:
[SETUP_RU.md](SETUP_RU.md). Не создавайте повторно действующие Worker и D1.
Изменения `wrangler.toml` применяются через `wrangler deploy`; секреты не хранятся
в этом файле. Не запускайте сбор диагностических логов с фото или токенами.
