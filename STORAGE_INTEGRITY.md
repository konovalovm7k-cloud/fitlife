# FitLife 4.5.1: надёжность сохранения

23 октября 2026 года. Рабочие экраны и ключи SharedPreferences сохранены.

## Исправленные сценарии

- Ручной ввод, каталог и AI раньше независимо читали/перезаписывали весь день.
  Теперь изменения проходят через общую очередь и применяются к свежей записи.
- Результат `false` от нативного сохранения больше не считается успехом. При ошибке
  кеш перечитывается, чтобы следующие операции не использовали несохранённые данные.
- Ошибка создания резервной копии повреждённого JSON останавливает перезапись.
- Повтор ручного/каталожного сохранения использует прежний ID. Даже если запись еды
  успела пройти, а список последних продуктов — нет, повтор не создаёт вторую еду.
- При ошибках добавления, правки, удаления, целей, веса и своих продуктов введённые
  значения остаются на экране. Успешное закрытие происходит после сохранения.
- Учёт воды меняется после подтверждения хранилища; быстрые нажатия не теряются.
- Описание еды при ошибке сервера больше не предлагает заменить фотографию.

## Проверки

`flutter analyze --no-pub`: замечаний нет. `flutter test --no-pub`: 70 тестов.
Новые проверки охватывают 20 одновременных записей из разных экземпляров репозитория,
параллельные ручную/фото/текстовую записи, отказ диска через false и exception,
невозможность сделать recovery-копию, позднее завершение после тайм-аута, повтор
со стабильным ID и ошибки сохранения в интерфейсе. Предыдущие тесты сохранены.

Release APK и GitHub Actions проверяются для нового коммита отдельно; зелёный
workflow 4.5.0 не подменяет проверку 4.5.1. Применяется прежняя подпись, персональное
автоподключение собирается только локально. Новый доступ или дополнительная квота
Google не создаются. PR #2 остаётся открытым без автоматического объединения.

Первый прогон CI 4.5.1 загрузил FitLife, но окно ANR самого Pixel Launcher перекрыло
главный экран. Диагностика сохранена в артефакте неуспешного run `39938580327`.
Smoke harness теперь записывает и закрывает только одно точно распознанное
системное окно этого лаунчера, не ANR приложения. Повторный сбой лаунчера проваливает
тест. Повторный run `39939742218` подтвердил закрытие системного окна, но выявил
сброс прокрутки до нажатия «Вода». Повторный поиск прокручиваемых элементов теперь
восстанавливает позицию после этого окна. Шесть Python-тестов проверяют ограничения
и повторную прокрутку; они включены в Actions. Проверки записи воды не отключены.

## Границы

Очередь координирует один Flutter isolate. Это не синхронизация разных телефонов
и не гарантия сохранения при физическом повреждении диска или завершении процесса.
Несколько ключей SharedPreferences не являются общей транзакцией: например,
частично записанные цели нужно повторить, а запись еды и список последних продуктов
могут сохраниться отдельно. Исходная еда при этом хранится внутри дневника.

Нативное ожидание интерфейса ограничено 15 секундами. Запрос, уже принятый диском,
нельзя надёжно отменить: после тайм-аута он может завершиться. Повтор с того же
экрана обновляет прежнюю запись, а не создаёт новую. Новый живой текстовый запрос
Gemini по-прежнему ожидает разрешения на тестовую квоту; это не обходится.
