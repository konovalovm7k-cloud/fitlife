# Journable: полезные сценарии для FitLife 4.5

22 октября 2026 года. Изучены [официальный сайт](https://www.journable.com/) и
[карточка Android-приложения](https://play.google.com/store/apps/details?id=com.journable.app).
Это анализ опубликованных возможностей, а не тестирование платной версии Journable
или независимая проверка точности её AI. Дизайн, тексты и ассеты не копировались.

## Вывод

Главная полезная идея: сократить путь от «что я съел» до понятной записи. Для этого
нужны несколько способов ввода, быстрый доступ к привычной еде, понятные цели и
обзор регулярности. Чат сам по себе не важнее сохранности дневника и возможности
исправить оценку. FitLife сохраняет собственные Manrope, зелёную палитру и навигацию.

| Сценарий из официального описания Journable | Решение в FitLife |
| --- | --- |
| Еда обычным текстом | Добавлено «Описать еду»: текст, согласие, AI-разбор, редактирование и подтверждение |
| Анализ фото | Уже работал; добавлено автоподключение в персональном APK, фото не отправляется автоматически |
| Быстрый повседневный ввод | На «Сегодня» и «Питание» добавлены три входа: описание, фото, поиск |
| Избранное и последние продукты | Уже реализованы, сохранены без переписывания |
| Личные цели и макросы | Уже реализованы; существующая проверка целей и пересчёт сохранены |
| Вода | Уже хранится по дням; включена в текст недельного отчёта там, где есть данные |
| Недельные отчёты | Добавлен локальный обзор 7 дней, переход в день и копирование отчёта |
| Подробные нутриенты | Каталог с источниками сохранён. AI не выдаёт неподтверждённые витамины за измеренные данные |
| Напоминания, тренировки, график массы | Не реализованы этим обновлением: потребуют отдельных данных, разрешений и приёмки |

## Что отличается намеренно

- AI-результат не попадает в дневник без подтверждения. Можно изменить вес, КБЖУ,
  название, состав и приём пищи. Оценки по тексту и фото имеют разные пометки.
- Текст и фото используют один серверный лимит; сменой способа ввода его не обойти.
- Пропуски недели не превращаются в нулевое питание. Повреждённые дни не входят
  в среднее; исходный дневник не заменяется пустым. Нет выдуманных серий привычек.
- Старые дни не сравниваются с сегодняшними целями: история целей пока не хранится.
- Копирование отчёта происходит только по нажатию. История целиком не отправляется
  в Google, и скрытого обмена с тренером или внешним сервисом нет.
- Нет обещания точного веса, скрытого масла или гарантированной калорийности по фото.
- Ручной ввод и локальная история работают без интернета и без подписки Journable.

## Автоподключение

По выбору владельца создан режим персональной сборки. HTTPS-адрес и личный код
передаются только локальной сборке через `--dart-define-from-file`. При первом
открытии модуля код сохраняется в защищённом хранилище. Явное отключение сохраняется,
есть отдельная команда восстановления. Ручные настройки не затираются.

Ключ Google остаётся в Cloudflare Secret. Личный код FitLife в персональном APK
извлекаем: получивший APK сможет использовать его квоту. Поэтому такой файл не
публикуется в GitHub или Actions; общая сборка не содержит персональных данных.
Это не публичная регистрация и не новый неавторизованный AI-прокси.

## Приёмка

Проверяются старые сценарии дневника, автоподключение/отключение/восстановление,
согласие на текст, контракт и пометка AI, повтор записи без дублей, средние недели,
маленький экран, серверные квоты и настоящий Workers/D1 runtime. Release APK
проверяется на Android с прежней подписью и без удаления данных. Физический S23
проверяется отдельно владельцем: телефон к компьютеру не подключён.
