# P0.4: единые расчёты целей FitLife

21 октября 2026 года. Версия **4.4.3+13**. Основа: `3c8f130` из
[PR #5](https://github.com/konovalovm7k-cloud/fitlife/pull/5).
Ветка продолжения: `codex/p0-nutrition-consistency`.

## Исправленная ошибка

Старый калькулятор округлял углеводы до целых граммов и принудительно назначал
не менее 80 г. Для цели 1200 ккал, 160 г белка и 40 г жира получалось 80 г
углеводов: энергия БЖУ составляла 1320 ккал. Теперь остаток — 50 г, и сумма
равна 1200 ккал. Для прежнего тестового профиля 2256 ккал / 148 г белка /
75 г жира углеводы теперь 247.25 г вместо 247 г.

## Реализовано

- Одна модель `NutritionGoalSettings` для ручных и расчётных целей. Имя
  `NutritionGoals` оставлено как совместимый псевдоним. Состояние приложения,
  форма, контроллер и репозиторий используют общую валидацию и расчёт.
- Формула бюджета: `У = (Ккал − 4 × Б − 9 × Ж) / 4`. Отдельный минимум
  углеводов устранён. Нулевой остаток допускается; избыток энергии белка и
  жиров отклоняется. Допуск `1e-8 ккал` устраняет только ошибки представления
  десятичных чисел в binary double, например 23.3 и 1.1×4 + 2.1×9.
- Форма целей показывает углеводы при вводе. При ошибке или пустом поле
  неправильный предпросмотр скрыт; сохранённые значения и черновик остаются.
- Профиль показывает все БЖУ и клетчатку. Дробные цели отображаются также
  в суточной карточке и показателях прогресса. Формат — до двух десятичных
  знаков с запятой; расчёт и запись сохраняют полную точность.
- JSON версии 1 и все ключи сохранены. Углеводы производны и отдельно в файл
  не записываются. Не требуется миграция уже сохранённых целей.
- Калькулятор проверяет конечность, единицы и технические диапазоны входа.
  Неизвестное значение пола больше не выбирает женскую формулу молча.
  Несовместимый бюджет возвращает понятную ошибку, без подмены результата.
- Прежняя неактивная оболочка использует ту же модель. При некорректном
  сохранённом профиле показывает базовые цели с сообщением о необходимости
  исправить данные. В форме профиля устранено освобождение контроллеров
  до завершения анимации закрытия; проверена повторная коррекция возраста.
- Калорийность и нутриенты продуктов не переписывались. Справочные калории
  еды могут отличаться от простого 4/9/4; для дневника сохранён исходный состав.

## Методика и границы

Существующая формула расхода сохранена: Mifflin–St Jeor, вес в кг, рост в см,
возраст в годах: `10×вес + 6.25×рост − 5×возраст + 5` для мужской формулы,
`−161` вместо `+5` для женской. Затем коэффициент активности и вычитание
заданного дефицита. Источник формулы:
[Mifflin et al., 1990, PubMed](https://pubmed.ncbi.nlm.nih.gov/2305711/).
Общие энергетические коэффициенты 4/4/9:
[FDA Food Labeling Guide](https://www.fda.gov/media/81606/download).

Прежняя политика калькулятора не модернизировалась: округление калорий с
нижним порогом 1200, белок `max(90, round(вес×1.6))`, жир
`max(35, round(калории×0.30/9))`, дефицит по умолчанию 450. Эти параметры —
наследие приложения, а не подтверждение индивидуальной пригодности нормы.
В активной оболочке по-прежнему ручные цели; персональный профиль относится
к P1.3 и должен отдельно определить политику расчёта и применимость.

Проверяемый технический вход калькулятора: вес 30–300 кг, рост 100–250 см,
возраст 18–120, активность 1–3, дефицит −2000…2000 ккал. Это границы ввода,
а не рекомендации. Бюджет должен проходить общую проверку. Прежние границы
ручных целей сохранены: 1–10000 ккал, белок/жир/клетчатка 1–1000 г.

## Проверки

Добавлены 18 тестов: 7 модели, 4 калькулятора, 7 интерфейса. В одном из тестов
576 комбинаций проверяют согласованность калорий с энергией БЖУ. Есть проверки
NaN/Infinity, неизвестного пола, диапазонов, реального превышения, точного
нулевого остатка, дробного ввода с точкой/запятой, холодного запуска, компактного
экрана с клавиатурой, восстановления старого профиля и неизменности данных
после отклонённого сохранения. Все 92 предыдущих теста сохранены.

| Проверка | Результат |
| --- | --- |
| `flutter analyze --no-pub` | Без замечаний |
| `flutter test --no-pub` | 110 тестов успешно |
| `git diff --check`, компиляция Python smoke-скрипта | Успешно |
| Локальная release-сборка | APK 4.4.3+13 собран, 56.2 MB |
| GitHub Actions и Android 15 release smoke | Итог фиксируется в описании PR |

Release smoke проверяет целые цели и 282.5 г углеводов, затем дробный снимок
2400.5 ккал / 160.25 г белка / 70.5 г жира / 35.25 г клетчатки и производные
281.25 г углеводов после холодного запуска. Старые проверки воды, обновления,
ручного дневника и защищённого подключения сохранены.

Локальная сборка использует `--android-project-arg=kotlin.incremental=false`
для проекта и SDK на разных дисках Windows; GitHub Actions использует штатную
команду. Пользователю передаётся облачный APK после проверки release-подписи.
Физический телефон отдельно не проверялся. Общие ограничения хранения и
внешнего анализа фото остаются описаны в предыдущих отчётах.
