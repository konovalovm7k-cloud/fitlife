# Подключение базы продуктов health-diet.ru

25 октября 2026. Присланная страница
[«Жиры и масла»](https://health-diet.ru/base_of_food/food_24515/) содержит КБЖУ
на 100 г, ссылки на карточки и несколько одноимённых вариантов продуктов.
На ней есть нулевая строка «Масло пловное», которую нельзя автоматически считать
подтверждённым продуктом с нулевой калорийностью.

Пункт 6.13 [пользовательского соглашения](https://health-diet.ru/info/termsOfUse.php)
запрещает автоматизированный сбор информации. Массовый сбор не выполнялся.
Для полного импорта нужна официальная выгрузка и согласование использования
в распространяемом приложении. robots.txt сам по себе не является лицензией.

## Что уже готово

`tool/import_food_catalog.py` читает локальный CSV, проверяет весь файл и создаёт
JSON для `assets/data/food_catalog.json`. Дополнительные записи автоматически
подключаются к экрану «База продуктов», сохраняются в дневник и доступны офлайн.
Согласованная выгрузка health-diet.ru ещё не получена. Сейчас asset содержит
отдельную подборку 40 продуктов [CoFID 2021](COFID_CATALOGUE.md), а прежний
небольшой справочник сохранён. Источники не подменяют друг друга.

```sh
python tool/import_food_catalog.py authorized-export.csv assets/data/food_catalog.json --source "health-diet.ru, согласованная выгрузка"
flutter test
flutter build apk --release
```

Столбцы: `id,name,kcal,protein,fat,carbs,source_url`. Все значения — на 100 г.
Поддерживаются разделители запятая/точка с запятой/табуляция и десятичная запятая.
Постоянный ID исходного продукта обязателен. Продукты с одинаковыми названиями
не сливаются. Отрицательные, бесконечные значения, повторные ID, неправильные
единицы, масса БЖУ больше 105 г и небезопасные адреса отклоняются. Допуск 5 г
служит только для округлений; импорт не подтверждает научную точность источника.

Клетчатка, витамины, минералы и степень приготовления не выводятся из КБЖУ.
Отсутствующие данные помечаются; оригинальное наименование сохраняется.
Импорт не меняет существующие записи дневника и не требует сервера на телефоне.
