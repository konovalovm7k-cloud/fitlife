# FitLife v3
Новая версия включает:
- онбординг;
- профиль и расчёт калорий/БЖУ;
- база продуктов;
- свои продукты;
- создание рецептов;
- дневник питания;
- история веса и график;
- вода и быстрые действия;
- расширенная статистика;
- локальное хранение данных.

Сборка APK:
flutter pub get
flutter build apk --release
