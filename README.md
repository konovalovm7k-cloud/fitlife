# FitLife 4.6.8

Локальный справочник расширен 20 продуктами CoFID 2021: состояние продукта,
источник и известная клетчатка сохраняются вместе с порцией. Неизвестные
нутриенты не подменяются измеренным нулём. [Данные и лицензия](COFID_CATALOGUE.md).
Экран «Сегодня», добровольные наблюдения голода и короткие уроки работают
с локальным сохранением. Экспериментальная сытость не прогнозирует точные часы:
[метод](SMART_SATIETY.md), [наблюдения](HUNGER_OBSERVATIONS.md),
[уроки](NUTRITION_LESSONS.md).

Сохранённые блюда, повтор питания, история веса и импорт каталога из локальной
работы Codex объединены с контроллером и миграциями P0.
[Учёт предыдущей работы и проверки](CODEX46_INTEGRATION.md),
[последовательность этапов](DEVELOPMENT_STEPS.md).

Офлайн-дневник питания на Flutter: калории и макросы, продукты и порции,
избранное, собственные продукты, вода по дням и редактирование целей.
Записи сохраняются на устройстве. Дата на главном экране открывает историю.
В форме целей показан расчёт углеводов из оставшихся калорий. Дробные цели
сохраняются без округления; профиль показывает калории, БЖУ и клетчатку.
Проверки расчётов: [P0_NUTRITION_VERIFICATION.md](P0_NUTRITION_VERIFICATION.md).

Камера/галерея и текстовый ввод через V2 предлагают название и массу продуктов.
AI не поставляет КБЖУ: пользователь выбирает каталог или переносит этикетку,
Nutrition Engine пересчитывает порцию, затем требуется подтверждение записи.
Перед отправкой фото/текста требуется согласие. Ввод этикетки работает офлайн.
[Проверка источников](SOURCE_CONFIRMED_MEALS.md),
[уточнение старых записей](DIARY_SOURCE_CORRECTION.md).

Для AI нужен общий сервер Cloudflare Worker/D1 в аккаунте владельца. Ключ Google
хранится только на сервере, пользователям выдаются отдельные отзываемые коды.
В APK нет рабочего облачного адреса или общего ключа: подключение настраивается
в приложении после развёртывания. Бесплатные тарифы ограничены квотами и регионами.
Инструкция: [server/SETUP_RU.md](server/SETUP_RU.md).
Подробный план: [PHOTO_ANALYSIS_PLAN.md](PHOTO_ANALYSIS_PLAN.md).
Результаты локальных проверок: [PHOTO_ANALYSIS_VERIFICATION.md](PHOTO_ANALYSIS_VERIFICATION.md).

## Проверка и сборка

Flutter **3.44.7**, Dart **3.12.2**, JDK **17**, Android SDK **36**.
Android-проект и `pubspec.lock` уже в репозитории. Не запускайте
`flutter create` поверх проекта для обычной сборки.

```sh
flutter pub get --enforce-lockfile
flutter analyze
flutter test
flutter build apk --release
```

APK: `build/app/outputs/flutter-apk/app-release.apk`. Поддерживается Android 7.0+.
Инструкция облачной сборки и подписи: [CLOUD_BUILD.md](CLOUD_BUILD.md).
Обзор структуры: [ARCHITECTURE.md](ARCHITECTURE.md).

## Проверка Android Release

В 4.3.1 исправлено зависание при первом запуске: R8 должен сохранять
Kotlin-типы, к которым `shared_preferences_android` обращается через JNI.
Оптимизация release остаётся включённой. Ошибка или тайм-аут чтения теперь
показывают повторную попытку, а не открывают пустой дневник поверх сохранённых данных.

CI устанавливает готовый release APK на Android 15 и проверяет главный экран,
запись воды, холодный перезапуск, установку поверх приложения без удаления данных
и защищённое хранение/чтение/удаление подключения к серверу. Дополнительно
проверяются ручная запись еды и восстановление целых и дробных целей вместе
с рассчитанными углеводами после холодного запуска.
Для запуска той же проверки на отдельном тестовом эмуляторе:

```sh
python3 tool/android_release_smoke.py build/app/outputs/flutter-apk/app-release.apk
```

Скрипт не работает с физическими телефонами и не очищает данные. XML экрана,
скриншоты и журнал процесса сохраняются в `build/release-smoke/`.

Сервер проверяется отдельно (Node.js 24, pnpm 11.25.0):

```sh
cd server
pnpm install --frozen-lockfile
node --test
pnpm exec wrangler deploy --dry-run --outdir dist/worker
```

Включён интеграционный тест настоящего Workers runtime/D1 с подставным Gemini.
Проверка реального AI требует ключа и развёрнутого сервера.

## Превью интерфейса

```sh
flutter test test/support/preview_ui.dart
```

Команда создаёт PNG экранов в `dist/` с тестовыми записями и настоящими шрифтами.
Тестовые данные не попадают в установленное приложение.
Manrope поставляется локально с лицензией SIL OFL в `assets/fonts/OFL.txt`.

Интерфейс развивает собственный зелёный стиль FitLife. Идея короткого пути
от записи еды к понятному дневному балансу вдохновлена
[Journable](https://www.journable.com/), без копирования экранов и ассетов.
