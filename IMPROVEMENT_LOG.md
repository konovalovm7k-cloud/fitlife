## Этап P0.1: сохранение дневника и достоверность чисел

Реализовано в этом продолжении:

1. Общий `DiaryRepository` для ручного ввода, каталога, редактирования, удаления
   и подтверждённых фото. Чтение и изменение дневника выполняются последовательно
   в одном isolate с перечитыванием реального хранилища перед записью.
2. Проверка результата записи. При `false` или исключении обновление не
   публикуется в интерфейсе; оптимистический кэш SharedPreferences перечитывается.
3. Ручная форма сохраняет выбранный продукт, приём пищи и дробную порцию после
   ошибки, показывает сообщение и позволяет повторить. Стабильный ID формы
   исключает дубликат при повторе. Дата фиксируется при открытии формы.
4. Каталог обрабатывает ошибку сохранения и блокирует повторный параллельный
   запуск добавления. Продукт остаётся доступным в общем поиске, как прежде.
5. Повреждённый дневник нельзя заменить, если не удалось сохранить recovery-копию.
   После неуспешной записи копии следующая попытка действительно пишет её на диск.
   Сохраняются также исходные значения неправильного типа.
6. Отрицательные и бесконечные нутриенты, NaN и повреждённые карты состава
   отклоняются при чтении. Порции не допускают отрицательный вес, NaN и Infinity.
   Расчёт выполняется без округления промежуточных значений:
   `значение порции = значение на 100 г × граммы / 100`.

Новые проверки: конкурентные записи и разные даты, отказ диска и повтор,
блокировка записи при отказе recovery-копии, сохранение неправильного типа,
точность дробных порций, ручной ввод и редактирование при ошибке,
совместное сохранение обычного блюда и фото, недопустимые значения состава.

Проверки этапа P0.1 (Flutter 3.44.7 / Dart 3.12.2):

| Проверка | Результат |
| --- | --- |
| `flutter pub get --enforce-lockfile` | Успешно, сохранён существующий lockfile |
| `flutter analyze --no-pub` | No issues found |
| `flutter test --no-pub` | 53 теста успешно; 9 новых сценариев |
| `flutter build apk --release --no-pub --android-project-arg=kotlin.incremental=false` | Release APK собран, 55.9 MB |
| `git diff --check` | Успешно |
| GitHub Actions APK и release smoke на эмуляторе | Запускаются в проверках PR; итоговая ссылка и статус фиксируются в описании PR |

Локальный флаг Kotlin устраняет ошибку incremental cache при размещении
проекта на диске C: и зависимостей на E:. Это настройка конкретного запуска,
а не изменение сборки CI. Локальный APK собран со стандартной debug-подписью
для проверки release-кода; он не заявляется как обновление установленного
приложения с прежним release-сертификатом. GitHub Actions использует ранее
настроенные секреты release-подписи, если они доступны.

Ограничения: SharedPreferences не даёт гарантию сохранности при внезапном
отключении питания; очередь действует внутри одного isolate. В этом этапе
не заявляется полная транзакционность всех настроек. Вода, цели, избранное
и создание собственного продукта требуют отдельного следующего изменения.
