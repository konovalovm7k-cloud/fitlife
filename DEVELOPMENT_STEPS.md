# FitLife: последовательная разработка

Единый рабочий чат: «FitLife — разработка приложения» (закреплён).
Работаем в существующем репозитории `konovalovm7k-cloud/fitlife`.
Каждый этап: исходники → профильные тесты → полный анализ и тесты → release APK
→ Android smoke → отдельные коммиты/PR → подтверждённые результаты.
Не сливать PR вслепую, не терять локальную работу, данные и подпись.

| Шаг | Работа | Критерий завершения |
|---|---|---|
| 0A | Интеграция #2–#6 | Обе истории сохранены; миграции, контроллер, точные цели, фото/текст и сводка работают вместе; подписанный APK и native smoke проходят |
| 0B | Локальная работа Codex 4.6 | Сохранённые блюда, повтор питания, история веса и импорт каталога перенесены на общий контроллер; тесты и APK проходят; iOS проверяется отдельно |
| 1A | «Сегодня» и питомец | Быстрый ввод, БЖУ/клетчатка, конкретное следующее действие; нет выдуманных веса/шагов; нейтральные состояния питомца, без наказаний и наград за голод |
| 1B | Простая камера | Снимок → согласие → распознавание → правка/подтверждение → сохранённый дневник; отмена, отсутствие сети и ошибки не теряют данные |
| 1C | Источники питания | AI предлагает идентичность/порцию; КБЖУ привязаны к источнику и считаются Nutrition Engine; неизвестный состав явно неполон |
| 2A | «Умная сытость» | Локальная документированная экспериментальная шкала 1–10; масса, белок, клетчатка, вода, энергоёмкость и структура; блюдо оценивается целиком; нет точных часов и псевдомедицинских обещаний |
| 2B | Калибровка | Добровольная локальная оценка голода спустя время, сохранение/отказ/удаление; персональные выводы только при достаточных данных |
| 3 | Задания, обучение и поддержка | Небольшие полезные действия, доступная информация о нутриентах и источниках; без поощрения дефицита еды |
| 4 | AI Chef | Сначала локальные блюда/правила; редкие запросы при явной потребности, источник состава и подтверждение |
| 5 | Медицинский модуль | Отдельное обоснование, требования к приватности/качеству и проверка специалистом до продуктовой реализации |

Для камеры, сытости и питания не подменять тесты реальным подтверждением точности.
Не называть физический телефон или iPhone проверенными по результатам эмулятора.
Не публиковать приложение и не увеличивать серверные лимиты без отдельной задачи.
